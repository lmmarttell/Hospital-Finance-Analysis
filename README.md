# Hospital Finance Analysis

## Project Overview
This project analyzes hospital financial performance using Excel, SQL, and Tableau.

## Tools Used
- Excel
- SQL (MySQL)
- Tableau

## Business Questions
1. What is the total revenue generated?
2. Which department generates the highest revenue?
3. What are the average treatment costs?
4. How does revenue vary by patient type?

## Project Workflow
1. Cleaned and prepared healthcare financial data in Excel.
2. Imported data into MySQL.
3. Performed financial analysis using SQL queries.
4. Created an interactive dashboard in Tableau.

## Files
- Hospital_Finance.xlsx
- Hospital_Finance.csv
- Hospital_Finance_SQL_Queries.sql
- HealthcareRevenue Dashboard.png

## Key Insights

- Total hospital charges reached $19M across 1,487 patients.
- Total payments collected were $10.82M, resulting in a 56.2% collection rate.
- Outstanding Accounts Receivable totaled $8.45M, indicating opportunities to improve collections.
- The Emergency Department generated the highest charges at approximately $3.1M.
- UnitedHealthcare was the largest insurance payer by total charges.
